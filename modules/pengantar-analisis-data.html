📊 Pengantar Analisis Data

Analisis data adalah proses mengubah data mentah menjadi informasi yang bermakna untuk pengambilan keputusan.

1. Kumpulkan data
2. Bersihkan data (hapus duplikat, isi data kosong)
3. Olah & analisis (hitung, bandingkan, cari pola)
4. Visualisasikan (grafik, tabel)

Ganti file ini dengan materi pengantar analisis data Anda sendiri.
