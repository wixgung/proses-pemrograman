◈ Materi 1

Pengenalan Pemrograman

Sebelum belajar membuat program, yuk kenalan dulu dengan apa itu program dan apa itu algoritma. Cara menuliskan algoritma (deskriptif, pseudocode, diagram alir) akan kamu pelajari lebih detail nanti di tahap "Mendesain Solusi".

Apa itu Program?

Setiap hari kita memakai aplikasi di HP atau laptop — media sosial, kalkulator, game. Semua itu disebut program. Secara sederhana, program adalah kumpulan instruksi yang ditulis dengan bahasa yang bisa dipahami komputer, disusun secara logis dan berurutan, agar komputer bisa menjalankan tugas tertentu.

Menurut beberapa ahli: program dapat dipandang sebagai kumpulan source code yang ditulis programmer (Binanto), atau sederetan instruksi dalam bahasa yang dimengerti komputer (Yulikuspartono). KBBI sendiri mengartikan program (dalam konteks komputer) sebagai perintah yang diberikan kepada komputer agar menjalankan fungsi tertentu.

Aktivitas membuat program itulah yang disebut pemrograman.

Apa itu Algoritma?

Sebelum sebuah program bisa ditulis, kita perlu algoritma — yaitu urutan langkah logis dan berurutan untuk menyelesaikan sebuah masalah, yang nantinya baru diterjemahkan menjadi kode program.

Bayangkan resep masakan: sebelum memasak, kamu perlu tahu urutan langkahnya lebih dulu — bahan apa disiapkan, apa yang dilakukan lebih dulu, dan seterusnya. Programmer juga begitu: sebelum menulis kode, mereka merancang dulu "resep"-nya dalam bentuk algoritma. Ada tiga cara umum menuliskan algoritma ini, lengkap dengan contohnya, yang akan kamu pelajari nanti di tahap Mendesain Solusi.

Empat Tahap Proses Pemrograman

Membuat program itu mirip membangun rumah: tidak langsung memasang batu bata, tapi ada tahap merancang denah lebih dulu. Dalam pemrograman, urutannya adalah:

1. Menganalisis Masalah 2. Mendesain Solusi 3. Coding 4. Testing
TahapInti Kegiatan
1. Menganalisis Masalah
Analyzing		Memahami masalah yang harus diselesaikan: apa saja data masukan (input), apa yang harus diproses, dan apa hasil (output) yang diharapkan.
2. Mendesain Solusi
Problem Solving		Menyusun langkah penyelesaian dalam bentuk algoritma deskriptif, pseudocode, dan diagram alir — sebelum menuliskan kode sungguhan.
3. Coding
Implementasi		Menerjemahkan algoritma yang sudah dirancang menjadi kode program memakai bahasa pemrograman tertentu, misalnya C++.
4. Testing
Pengujian		Menjalankan program dengan berbagai data uji untuk memastikan hasilnya benar, termasuk kasus-kasus batas.

Mengapa Analisis Penting?

Sebelum menulis satu baris kode pun, seorang programmer perlu memahami dulu inti masalahnya. Kalau langsung "asal coding" tanpa analisis, program yang dihasilkan bisa saja salah arah atau tidak menyelesaikan masalah yang sebenarnya.

Pola pikir IPO banyak dipakai saat menganalisis masalah: Input (data apa yang tersedia/dibutuhkan), Proses (apa yang harus dilakukan terhadap data itu), dan Output (hasil apa yang diharapkan).

Simbol-Simbol Flowchart yang Sering Digunakan

Setiap bentuk pada flowchart punya arti yang berbeda. Berikut simbol dasar yang paling sering dipakai:

Proses

Input / Output

Decision
Percabangan berdasarkan syarat (ya/tidak)
Garis Alir

Contoh 1 — Algoritma Kegiatan Sehari-hari

Kasus: membuat teh manis hangat. Klik tab di bawah untuk melihat algoritma yang sama dituliskan dalam tiga bentuk berbeda.

1. Mulai
2. Siapkan gelas, teh celup, gula, dan air panas
3. Masukkan teh celup ke dalam gelas
4. Tuangkan air panas ke dalam gelas
5. Tunggu 3 menit hingga teh terseduh
6. Angkat kantong teh celup
7. Masukkan gula secukupnya, lalu aduk hingga larut
8. Sajikan teh manis hangat
9. Selesai
BEGIN SIAPKAN gelas, teh_celup, gula, air_panas MASUKKAN teh_celup KE gelas TUANGKAN air_panas KE gelas TUNGGU 3 menit ANGKAT teh_celup MASUKKAN gula, ADUK hingga larut OUTPUT "Teh manis hangat siap disajikan" END

Contoh 2 — Algoritma Program Sederhana: Lulus / Tidak Lulus

Kasus: tentukan status kelulusan siswa. Jika nilai ≥ 75, siswa dinyatakan Lulus; jika kurang dari 75, Tidak Lulus. Ini contoh algoritma yang nantinya akan kita ubah menjadi kode program sungguhan.

1. Mulai
2. Masukkan nilai siswa
3. Jika nilai ≥ 75 maka status = "Lulus"
4. Jika tidak, maka status = "Tidak Lulus"
5. Tampilkan status
6. Selesai
BEGIN INPUT nilai IF (nilai >= 75) THEN status = "Lulus" ELSE status = "Tidak Lulus" END IF OUTPUT status END

Dari Pseudocode ke Kode C++

Bandingkan pseudocode di tahap sebelumnya dengan kode C++ berikut. Perhatikan bahwa strukturnya sangat mirip!

#include <iostream> using namespace std; int main() { float nilai; cout << "Masukkan nilai: "; cin >> nilai; if (nilai >= 75) { cout << "Lulus"; } else { cout << "Tidak Lulus"; } return 0; }

Beberapa bagian penting:

  • float nilai; — membuat variabel untuk menyimpan nilai siswa (angka desimal).
  • cin >> nilai; — membaca nilai yang dimasukkan pengguna.
  • if (nilai >= 75) { ... } else { ... } — struktur percabangan, persis seperti pada pseudocode dan diagram alir sebelumnya.
  • cout << "..."; — menampilkan hasil ke layar.

Menguji dengan Data (Test Case)
